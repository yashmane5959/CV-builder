# CV Builder

A modern web-based tool for creating professional CVs with ease.

**Status:** 🚧 In Progress — Active Development
New features, improvements, and updates are coming soon.

## Overview

CV Builder is a web development project designed to simplify the process of creating a clean, structured, and professional CV. Users can enter their personal, educational, and technical information, and use the collected data to generate a CV in a consistent format.

## Why This Project?

Creating a CV from scratch can be time-consuming, especially for students and beginners. This project provides a simple interface that guides users through the required information and makes CV creation faster and more convenient.

## Features

### Planned / Current
- Personal information — name, email, phone, and date of birth
- Education details
- Technical and other skills
- Projects and achievements
- Language and English-level information
- Profile photo upload
- LinkedIn, GitHub, and portfolio links
- Responsive design for different screen sizes
- CV generation and professional formatting
